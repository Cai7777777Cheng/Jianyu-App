# 间语 · 静态 Demo

可双击打开的手机框交互示意，对齐《间语 · App 功能框架》与 UX v2：底部五栏、树洞定期总结授权转达、信笺箱、完整形象、通道菜单与小间电话边界。

**无真实后端、无 LLM API、无微信接入。** 全部为前端 mock。

## 如何打开

1. **双击** `index.html`（`file://` 即可）
2. 或任意静态服务器，例如：

```bash
cd jianyu-app-demo
python3 -m http.server 8765
# 浏览器打开 http://127.0.0.1:8765
```

无需构建、无需安装依赖。建议用现代浏览器（Chrome / Safari / Edge）。

## Demo 已覆盖模块

- **底部五栏**：首页·小间 / 树洞 / 信笺箱 / 我们 / 我的
- **认识小间**：气质 / 形象系 / 频率 / 称呼 / 禁忌；试聊回复随气质变；可「重新认识」
- **完整形象页（我的）**：SVG 占位形象、气质标签、禁忌、试聊、重新认识
- **树洞**：聊天 UI、「今天只倒苦水」、**本期总结**卡片 →「请小间转达」→ 通道菜单
- **信笺箱**：对方发来 / 己方发出；状态标签；轻回应三按钮（稍后 / 回一句 / 邀请一起聊）
- **我们**：已配对示意、红绿灯与通道矩阵开关、小约定 / 复盘入口
- **通道菜单**：短笺 / 语音代转 / 小间电话 / 暂停
- **小间电话**：全屏来电、身份说明（不冒充）、脚本预览、拒接→留言+短笺降级
- **首页**：主动触达气泡、「先跟小间说」、进行中任务
- **角标文案**：微信机器人私聊同步树洞；短笺确认回 App

## 已知限制

- 无账号、配对真链路、推送、TTS、真实通话
- 无微信服务号 / 企微机器人；仅文案说明边界
- 总结与短笺文案为写死 mock，不接模型
- 单人先用模式未单独做灰态全流程（框架有述，Demo 默认已配对）
- L0–L5 路由引擎仅文案/开关示意，无完整分型 UI
