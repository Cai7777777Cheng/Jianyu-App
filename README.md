# 间语 · 静态 Demo

两套可双击打开的手机框交互示意。没有后端、没有模型接口、没有微信接入，全部是前端 mock。

## 打开 2.0

1. **双击** `index2.0.html`（`file://` 即可）
2. 或任意静态服务器：

```bash
python3 -m http.server 8765
# 浏览器打开 http://127.0.0.1:8765/index2.0.html
```

无需构建、无需安装依赖。建议用现代浏览器（Chrome / Safari / Edge）。

`index.html` 是第一版，2.0 不覆盖它。

## 2.0 和 v1 的差别

| | v1 `index.html` | 2.0 `index2.0.html` |
|---|---|---|
| 第一眼 | 问候条、电光青长按钮、两张待办卡 | 小间占主视觉，一句问候，底部一颗圆形「跟小间说说」 |
| 小间 | 几何 bot，描边换色 | 钴蓝黏土信使：多层渐变、高光、软阴影；紫粉芽尖、黄橙围巾、白眼黑瞳 |
| 气质 | 改描边和表情 | 身体保持钴蓝，只改表情和围巾颜色。形象系只加星球环、圆耳朵或贴纸 |
| 同族 | 无 | 两侧更小的绿 / 橙小球，表示可以换气质，不是入口 |
| 控件 | 圆角卡片、描边按钮 | 大标题 / Title2 / 正文 / 脚注；分组列表；毛玻璃 Tab（选中钴蓝）；实心主按钮，次按钮为文字 |
| 待处理 | 两张强调卡 | 最多两行列表，弱于角色 |

信息架构相同：首页、树洞、信笺箱、我们、我的。树洞总结要你点头才转达。通道菜单和小间电话仍写明：不冒充、双方授权、每次确认、未接改成留言和短笺。微信只在「我的」用一段文案说明边界。

## 打开 v1

双击 `index.html`，或打开 `http://127.0.0.1:8765/`。

v1 是暖米白底、电光青主按钮、几何圆润的 bot。首页强调「先跟小间说说」，下面最多两张待处理卡。

## Demo 已覆盖（两版相同）

- **底部五栏**：首页 / 树洞 / 信笺箱 / 我们 / 我的
- **认识小间**：气质 / 形象系 / 频率 / 称呼 / 禁忌；试聊随气质变；可「重新认识」
- **我的**：完整形象、气质与禁忌、试聊、重新认识
- **树洞**：聊天、「今天只倒苦水」、本期总结 →「请小间转达」→ 通道菜单
- **信笺箱**：对方来信在上；轻回应（稍后 / 回一句 / 一起聊）
- **我们**：已配对、小约定、授权与通道开关
- **通道菜单**：短笺 / 语音代转 / 小间电话 / 暂停
- **小间电话**：来电身份（不冒充）、脚本、拒接后改成留言和短笺
- **首页**：问候、进入树洞、至多两条待处理（对方短笺 / 本期总结）
- **微信**：仅文案。私聊可同步树洞；短笺确认和电话回 App；不冒充

## 已知限制

- 无账号、配对真链路、推送、语音合成、真实通话
- 无微信服务号；只说明能力边界
- 总结和短笺是写死的文案
- 默认已配对，没有单独做「单人先用」灰态
- L0–L5 只在文案和开关里示意，没有完整分型界面
