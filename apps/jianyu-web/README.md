# 间语 · Vite 原型

心情应用配色的可运行界面。小间用 `public/xiaojian/` 里的锁定裁切 PNG。

```bash
cd apps/jianyu-web
npm i
npm run dev
```

浏览器打开终端打印的本地地址，默认是 http://127.0.0.1:5173 。

生产构建：

```bash
npm run build
```

离线静态对照页在仓库根目录，双击即可，不经过 Vite。交流插画在仓库根的 `channels/`。

- `index4.2.html`：当前演示（情绪卡、信札、小间来电、双边引导、日历约定）
- `index4.1.html`：上一版界面
